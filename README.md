# Ghost Inside · 白色走廊

## 运行

跨平台运行需要双方都安装 **Godot 4.7.2 Stable**，并用它打开 `game/project.godot`。Windows 和 macOS 用户都应在本机安装对应的 Godot 4.7.2 Stable export templates，然后从 Editor 的 **Project → Export** 导出本机版本；Windows 导出到 `game/builds/windows/`，macOS 导出到 `game/builds/macos/`（默认 ZIP 为 `GhostInside.zip`）。macOS 不能运行 Windows 的 `.exe`，Windows 也不应把 macOS 导出物当作可执行文件使用。构建输出不提交 Git。

如果导出列表中没有目标平台，请先在 Godot 的 **Editor → Manage Export Templates** 安装与编辑器完全匹配的 4.7.2 Stable templates。macOS preset 不包含签名证书、Apple ID 或任何密钥；需要签名/公证时由 macOS 用户在本机另行配置。两边也可以直接按 **F5** 在编辑器内运行项目。无需网络也可以完成案例。

编辑工程：使用 **Godot 4.7.2 Stable** 打开 `game/project.godot`，按 **F5** 运行整个项目。Compatibility，1280×720 横屏。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 调查 / 进入回忆 | 靠近后 E / Enter |
| 前往地图物品 | 点击物品名称，再按 E / Enter |
| 共鸣取证 | 靠近金色标记，Space；也可点击共鸣按钮 |
| 选卡 / 提交 | 鼠标；按钮支持键盘焦点 |
| 立即重开 | F2 或右上角重开 |

## 完整体验

授权进入 → 调查合照、成绩单、掌声终端 → 关闭掌声 → 进入回忆 → 三段闪避与共鸣 → 事实、感受、边界各选一张 → 可选补充不超过60字 → 林澈回应 → 查看保护机制、出口及结案变化 → 回到现实，林澈开口，父亲尚未回应。

回忆正常持续55秒。每段至少听4秒，靠近金色标记释放共鸣；取证后继续观察至片段结束。前两次同步中断恢复当前片段，第三次返回地图并将证据变灰。重新进入并共鸣可恢复。修改最多再次提交一次，也可以保留林澈的改写。

三种可复现组合（短句留空）：

| 事实 | 感受 | 边界 | 回应 |
|---|---|---|---|
| F02 | E03 | B02 | 接受 |
| F03 | E01 | B01 | 修改 |
| F01 | E02 | B03 | 暂时保留 |

不同回应改变怪物颜色与形态、出口名称和结案文字。所有结果保留职业选择与父亲回应的不确定性。

## 在线评估（可选）

默认使用案例本地回应。设置以下进程环境变量后，在标题勾选“在线评估”：

- `GHOST_AI_URL`：支持 OpenAI chat completions 格式的完整 HTTPS 地址。
- `GHOST_AI_MODEL`：模型名称。
- `GHOST_AI_KEY`：接口密钥。请勿写入工程、截图或分享文件。

返回只允许 accept、revise、hold，并检查字段、证据和结果对应关系。非法结果仅重试一次；网络异常或总等待约7.8秒后采用案例本地回应。当前未配置真实模型服务；已通过本地 HTTP 模拟验证成功、非法、断开和超时。

Ghost 轨迹是简化操作记录；“记忆写入”只保留本次案例，重开后清除，不建立存档。
