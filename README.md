# Ghost Inside · 白色走廊

## 运行

直接打开 `game/builds/windows/GhostInside.exe`。无需安装 Godot，无网络也可以完成案例。

编辑工程：使用 **Godot 4.7.2 Stable** 打开 `game/project.godot`，按 **F5** 运行整个项目。Compatibility，1280×720 横屏。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 切换记忆频段 | 数字 1 / 2 / 3（事实 / 情绪 / 期待） |
| 调查 / 进入回忆 | 靠近后 E / Enter |
| 前往地图物品 | 点击物品名称，再按 E / Enter |
| 共鸣取证 | 靠近金色标记，Space；也可点击共鸣按钮 |
| 选卡 / 提交 | 鼠标；按钮支持键盘焦点 |
| 立即重开 | F2 或右上角重开 |

## 完整体验

授权进入 → 在事实、情绪、期待三个频段观察白色走廊 → 调查合照/优秀履历、成绩单/录取档案、掌声/意愿终端 → 关闭掌声 → 进入三段因果回忆 → 闪避与共鸣 → 事实、感受、边界各选一张 → 可选补充不超过60字 → 林澈接受、修改或暂时保留 → 查看价值清算者、出口和结案变化 → 回到现实，林澈承认“不知道”，画面在父亲回应前结束。

故事采用“五屏程序、六章叙事”：成长档案、封存工作室、未来验证、林远房间和自我手术都被压缩进一张走廊与三段回忆。玩家会亲自发现：林远自己填写医学志愿；林澈没有代填；Dream_Project 由林澈亲手封存；父亲的影响同时包含爱、失败恐惧、保护与限制；成功和失败都不能反推最初意愿。最终固定把 `SELF_INTENT` 从 `ERROR` 改为 `UNCONFIRMED`，不替林澈选择医学或游戏。

回忆正常持续55秒。每段至少听4秒，靠近金色标记释放共鸣；取证后继续观察至片段结束。前两次同步中断恢复当前片段，第三次返回地图并将证据变灰。重新进入并共鸣可恢复。修改最多再次提交一次，也可以保留林澈的改写。

三种可复现组合（短句留空）：

| 事实 | 感受 | 边界 | 回应 |
|---|---|---|---|
| F02 | E03 | B02 | 接受 |
| F03 | E01 | B01 | 修改 |
| F01 | E02 | B03 | 暂时保留 |

不同回应改变怪物颜色与形态、出口名称和结案文字。所有结果保留职业选择与父亲回应的不确定性。

## 在线评估（可选）

默认使用案例本地回应。设置以下进程环境变量后，在标题勾选“在线评估”：

- `GHOST_AI_URL`：支持 OpenAI chat completions 格式的完整 HTTPS 地址。
- `GHOST_AI_MODEL`：模型名称。
- `GHOST_AI_KEY`：接口密钥。请勿写入工程、截图或分享文件。

返回只允许 accept、revise、hold，并检查字段、证据和结果对应关系。非法结果仅重试一次；网络异常或总等待约7.8秒后采用案例本地回应。当前未配置真实模型服务；已通过本地 HTTP 模拟验证成功、非法、断开和超时。

Ghost 轨迹是简化操作记录；“记忆写入”只保留本次案例，重开后清除，不建立存档。

## 范围

已实现：五场景、单案例调查、五区白色走廊地图、三种记忆频段、角色投影、回忆闪避、三次同步机会、灰色证据恢复、三类卡片、有限修改、离线回应、可选在线接口、可见世界变化、开放结局、演示预警、立即重开、中文像素字体、背景音乐与五种音效。

没有制作第二案例、账号、存档、设置菜单、手机或网页版本。没有导入整套 Unity Office 工程或转为 3D。真实模型服务与其他电脑的硬件兼容性尚未验证。

地图内“心灵调理师”当前使用已有全身形象缩小显示，并具有朝向翻转和步态起伏。四方向 4×4 像素步行动画曾提交生成，但图片服务网络失败；可直接复用的地图背景、步行动画和角色小人提示词保存在 `game/assets/prompts/`，替换时无需改动玩法。

验证记录与截图见 `artifacts/` 和 `TEST_REPORT.md`。
