# Ghost Inside · 案例 001 白色走廊

## 运行

直接打开 [GhostInside.exe](game/builds/windows/GhostInside.exe)。无需安装 Godot，无网络也能完整通关。

编辑工程：使用 Godot 4.7.2 Stable 打开 [project.godot](game/project.godot)，按 F5。工程为 Compatibility 模式，1280×720 Windows 横屏。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 调查 / 操作装置 | E / Enter；也可直接点击物件或装置 |
| 切换事实、情绪、期待频段 | 数字 1 / 2 / 3 |
| 查看三层卡关提示 | Space |
| 打开意愿档案 | 右上角“意愿档案” |
| 重开案例 | F2 或右上角“重开” |

## 完整流程

授权进入后，游戏按以下顺序开放六个单屏意识空间：

1. 白色走廊：为四段履历补齐动机，发现“医学录取”的意愿字段为空。
2. 成长档案室：排列家庭照片，把旧吉他拨片放入投影仪，确认父亲的影响同时包含爱、恐惧、保护与限制。
3. 废弃游戏工作室：恢复 WORLD → CHARACTER → ENDING 模块，确认 Dream_Project 由林澈亲手封存。
4. 未来验证中心：完成林宇与陈默两组人生模型，证明稳定成功和自由失败都不能反推最初意愿。
5. 林远的房间：用三档台灯确认林远亲自填写医学志愿，恢复镜中轨迹，并排除三段虚构回答，留下 7.4 秒沉默。
6. 自我手术室：运行三种可撤回的错误诊断，把前四场核心证据放入手术台，将自我意愿从 ERROR 改为 UNCONFIRMED。

结局不会替林澈选择医学或游戏。两个出口的选择按钮会消失，林澈只确认自己需要先理解为什么选择。系统根据玩家最先关注的证据生成责任型、探索型或融合型理解报告，事实结论保持一致。

## 地图与视觉

- 六个房间都有独立的固定镜头 2.5D 空间、行走范围、交互位置、出口和角色投影。
- 三个频段共用房间几何，只改变颜色、文字和隐藏线索。
- 现有 Character、Fonts、Space、UI 素材已进入工程；缺少的房间图片由程序化 2.5D 布景补足，因此不依赖外部素材也能通关。
- 角色当前使用已有立绘缩小为地图投影，心灵调理师具有移动朝向和步态起伏。
- Tripo 建议采用“3D 道具或房间 → 固定镜头 PNG → Godot 2.5D 分层”的方式。完整提示词见 [TRIPO_ASSET_PROMPTS.md](TRIPO_ASSET_PROMPTS.md)。
